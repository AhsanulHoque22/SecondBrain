# Octrees, Quadtrees, BSP-Trees & Fractal-Geometry Methods
> [[wiki/_index|← Course Index]] · [[_Topics]] · [[00_Dashboard]]

## Definition
Syllabus-mandated coverage from the secondary textbook (Hearn & Baker) — spatial data structures for representing solid objects (octrees, quadtrees, BSP-trees) plus procedural methods for modeling natural/irregular objects (fractal geometry).

## Key steps / algorithm
1. **Octree:** recursively subdivide a bounding cube into **8 octants** per node; homogeneous octants are leaves, heterogeneous ones subdivide further. Voxel = 3D unit of space. Used for solids, medical imaging, set operations (union/intersection/difference via octant scanning), visible-surface search (front-to-back octant order).
2. **Quadtree:** 2D analogue — **4 quadrants** per node instead of 8 octants.
3. **BSP tree:** **2** partitions per step using a cutting plane of **any position/orientation** (vs. octree's fixed axis-aligned planes) — adaptive, can be shallower than an octree for the same scene; used for visible-surface ID and ray-tracing space partitioning.
4. **Fractal object:** infinite detail + self-similarity, generated by repeating a transformation $F$: $P_1=F(P_0), P_2=F(P_1),\dots$ — finite iterations in practice (display resolution limit).
5. **Classification:** self-similar (single scale factor $s$) → statistically self-similar (+ randomness, models plants) → self-affine (different $s_x,s_y,s_z$) → statistically self-affine (models terrain/water/clouds) → invariant sets (self-squaring e.g. Mandelbrot, self-inverse).
6. **Fractal dimension:** $D=\ln n/\ln(1/s)$ for $n$ subparts at scale $s$. Koch curve: $D=\ln4/\ln3\approx1.262$. Fractal tetrahedron surface: $D=\ln6/\ln2\approx2.585$. Curves have $D>1$, surfaces $2<D\le3$, solids $3<D\le4$ — always exceeds the Euclidean dimension.

## Weak spots / common mistakes
- Octree = 8 octants/node (3D), quadtree = 4 quadrants/node (2D) — don't swap the counts.
- BSP tree's key differentiator vs. octree: cutting plane can be **any** orientation (adaptive), not just the 3 axis-aligned planes — this is what makes it potentially shallower/faster to search.
- Fractal dimension always **exceeds** the topological/Euclidean dimension of the object — a fractal curve has $D>1$, not $D=1$.
- "BST-Tree" in the syllabus almost certainly means **BSP-Tree** (binary space-partitioning), not a generic binary search tree — the book's actual §10-17 heading is "BSP Trees."
