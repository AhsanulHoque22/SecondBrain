## The Day Map

```

  → Prayer (15 min)

5:00  PREP (10 min)
  → Review flashcard questions from previous days
  → No new learning yet — just recall

  → Hardest new topic of the day
  → Method: read once, then close notes + explain out loud
  → Active recall at 6:30 (10 min, notes closed)

6:40  BREAK (10 min)
  → Hydrate. Stand up. No phone.

6:50  PAST PAPER PRACTICE (30 min)
  → Topic-specific questions from _TopicQuestionMap.md
  → Timed. Write full answers.

7:20  TRANSITION (10 min)

7:30  BLOCK 2 — Deep Work (90 min)
  → Second topic or continuation of Block 1 topic
  → End with Feynman test: can you explain it without notes?

9:00  BREAK (10 min)

9:10  BLOCK 3 — Study (50 min)
  → Past paper tracing / numerical practice
  → End: update _Topics.md for topics covered

10:00 BREAKFAST (30 min)
  → Eat properly. This is not study time.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10:30 PAST PAPER PRACTICE (30 min)
  → Continue topic from morning blocks
  → Technique: write full structured answers

  → 5 min warm-up + 15 min cardio + 5 min cool-down
  → Non-negotiable. Stamina is built daily.

11:25 PUBLIC SPEAKING IN ENGLISH (30 min)
  → Explain today's study topic aloud in English
  → Record 90 sec. Listen back. Note 1 thing to improve.
  → This is Feynman + speaking practice + viva prep in one.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  → End: spaced rep pass on any topics from 2 days ago

13:00 GIRLFRIEND CHAT — Part 1 (30 min)
  → Undivided attention. Log off from study mode fully.

  → Only scheduled phone scroll of the midday.

14:30 BLOCK 5 — Timed Past Papers (120 min)
  → Exam simulation: timed, no notes, full answers
  → Multiple questions back-to-back
  → Review gaps at the end — rewrite incorrect parts cleanly

16:30 GIRLFRIEND CHAT — Part 2 (30 min)

17:00 BREAK / PHONE (30 min)
  → Last unstructured break of the day.

17:30 ASR PRAYER (15 min)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## Regular 7-Day Exam Cycle (Livora active)

During normal 7-day cycles (not the AI 12-day crunch), replace Block 4 with:

```
12:00  LIVORA BLOCK (2h MAX — hard cap)
  → Review overnight bot output (15 min)
  → Define today's ONE deliverable (15 min)
  → Build (60 min)
  → Test + commit + assign tomorrow's bot task (30 min)
  → STOP at 2h regardless
```

Reduce Block 5 to 90 min (14:30–16:00) to compensate.

---

## Last 2 Days Before Any Exam

```
Livora: 0 (suspended completely)
Public Speaking: keep 30 min (explain exam topics aloud — it's recall)
Girlfriend chats: keep (protect focus + mental health)

ALL remaining blocks → exam subject only:
  AM: Full timed past paper starting at 10:30 AM (simulate real exam)
  PM: Review paper results → fix every weak spot
  Block 6: Cheat sheet review + active recall pass over ALL topics
  Block 7: Final formula/definition dump from memory

Sleep early. A rested brain beats a cramming one every time.
```

```

   - What surprised you? (learn it properly for viva)
   - What was easy? (note your strengths)

   - Open 02_Courses/[NextCourse]/
   - Tell Claude: "Analyze past papers, rank topics by yield"
   - Read the priority list

3. Rest for the afternoon. You just sat a 4-hour exam.
4. Evening: first study block of the new subject — just 60 min, easy start.
