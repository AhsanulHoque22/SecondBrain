## Fit assessment

**Weakest fit of the four** — flagging this honestly rather than dressing it up. The JD wants hands-on model fine-tuning (PyTorch/TensorFlow/Hugging Face), LangChain/CrewAI/LangGraph, and vector databases — none of which show up anywhere in the project history, and the CV does not claim them. What's genuinely there is applied *systems* AI engineering: multi-provider LLM orchestration with cost-aware routing (Scraper Pipeline), RAG with prompt-injection defense (Livora), agent-based automation (Second Brain), and edge-inference deployment (AgroEdge AI). That's adjacent but not the same skill set as fine-tuning open-weight models. Worth applying because the company explicitly does applied LLM/RAG work commercially and the multi-LLM-cascade project is a strong, unusual signal — but expect this to be a harder sell than the other three.
