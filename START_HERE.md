# START HERE — 90-Minute Setup

This is your exam-season second brain. It is deliberately small. Do **not** add connectors,
agents, or automation yet — that comes during a later exam gap. Right now the only goal is:
get studying today.

## The 90-minute setup (do this once)

**1. Put this folder where Obsidian + Claude Code can both see it (10 min)**
- Move the whole `SecondBrain/` folder somewhere stable, e.g. `~/SecondBrain`.
- In Obsidian: *Open folder as vault* → select `SecondBrain`.
- In your terminal: `cd ~/SecondBrain` then run `claude` (Claude Code) **from inside this folder**.
  Claude Code automatically reads `CLAUDE.md` and becomes your study mentor.

**2. Load your real materials (40 min)**
- Drop your **AI (CSE 713)** materials into `02_Courses/CSE713_AI/`:
  - lecture slides, the textbook/PDFs, your own notes
  - **most important: past / previous-year question papers** → put them in `_PastPapers.md` or as PDFs in that folder
- Don't worry about the other 5 courses yet. One subject at a time.

**3. Fill the 3 blanks (10 min)**
- Open `00_Dashboard.md` and set your prayer times (they become your day's anchors).
- Open `02_Courses/CSE713_AI/_Syllabus.md` and paste your actual syllabus / topic list.
- Open `03_Daily_Logs/2026-05-29.md` — that's today's plan, already drafted for you.

**4. Start the engine (30 min)**
- In Claude Code, say: *"Read CLAUDE.md and today's daily log. Look at my AI syllabus and
  past papers, then give me the topic-priority list and start me on block 1."*
- Then study. The system works only if you actually open a topic file and start.

That's it. Everything else updates itself as you log your days.
